Aim-Training Shooting Game
Project Introduction
This project is a 2D aim-training shooting game implemented purely in Python based on the Pygame framework. The game simulates FPS combat scenarios to help users practise mouse aiming precision and reaction speed.
Game Overview
Within a 120-second timed match, multiple human-shaped targets spawn from distant positions on the screen and keep moving toward the player’s position. The game ends in defeat if any target reaches the player. Victory is achieved when all living targets are eliminated before time runs out.
Players can switch between two firearms: a semi-automatic pistol and an automatic rifle. Headshots will instantly destroy targets, while body hits require several shots to take down enemies. All audio effects including gunshots, hit sounds, reload and shell-eject sounds are dynamically generated by code, and no external audio assets are required. A real-time HUD presents key metrics: total points, hit count, shot count, shooting accuracy, remaining time, ammunition status and the number of alive targets.
Core Technical Features
1.	Object-oriented architecture: Clear separation between the backend logic module (target spawning, movement, collision detection, game rules) and the frontend rendering module (drawing characters, weapons, crosshair, UI and visual special effects).
2.	Depth-simulated rendering: Targets change visual size and brightness according to depth values, creating a pseudo-3D distance perception effect.
3.	Weapon simulation: Recoil animation, muzzle flash, tracer bullet and shell ejection visual effects; complete reload logic, magazine and reserve ammunition management.
4.	Procedural audio synthesis: Generate low-frequency deep gunfire, body-hit thud sounds and other sound effects through mathematical sine-wave calculation. All sound parameters can be directly adjusted in the source code.
5.	Performance protection mechanism: An upper limit is set for simultaneous living targets to avoid excessive computation and frame rate drop.
Operation Instructions
•	Mouse movement: Control crosshair aiming
•	Left mouse button: Fire weapon
•	1 / 2: Switch between pistol and rifle
•	E: Perform weapon reload
•	R: Restart current game round
•	ESC / Q: Exit game
Operating Environment
Python 3.x and pygame (or pygame-ce) library are required to run this project.
Short Version (for summary)
This is a 2D shooting aim-training game developed in Python with the Pygame library. Players fight continuously spawning moving human-shaped targets within a fixed time limit. It supports instant headshot kills and multi-hit body damage. Two weapons are available: a semi-automatic pistol and an automatic rifle. All sound effects are programmatically generated without external audio files. The real-time HUD displays score, hit count, shooting accuracy, ammo and other statistics. Built with object-oriented programming, the project separates backend game logic and frontend rendering for convenient modification and expansion.
